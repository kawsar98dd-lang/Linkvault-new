# BnlinkVault — Marketplace Readiness & Release Roadmap (বাংলা)

**সংস্করণ:** 0.2.1-prep  
**অবস্থা:** Foundation preparation package — **NOT PRODUCTION READY / NOT READY TO SELL AS A COMPLETE SaaS**.

এই নথি সোর্স কোডের বর্তমান অবস্থা ও পরবর্তী নিরাপদ কাজের ক্রম বোঝানোর জন্য। এটি কোনো সফল production build, penetration test বা hosting deployment-এর দাবি করে না।

## 1. এই আপডেটে কী পরিবর্তন হয়েছে

- main-only lockfile workflow-এ `git push --force` সরিয়ে স্বাভাবিক `git push` করা হয়েছে। Branch diverged হলে workflow নিরাপদে ব্যর্থ হবে; বিদ্যমান review branch জোর করে overwrite করবে না।
- README-তে marketplace readiness এবং Cloudflare compatibility সম্পর্কে স্পষ্ট সতর্কতা যোগ করা হয়েছে।
- Android ফোন থেকে পরবর্তী কাজ চালানোর জন্য বাংলা নির্দেশিকা যোগ করা হয়েছে।
- marketplace-ready হওয়ার গেট, ফিচার-পরিকল্পনা ও hosting সীমাবদ্ধতা লিখিতভাবে নথিভুক্ত করা হয়েছে।
- মূল অ্যাপের authentication, database, API, security বা existing source files মুছে ফেলা/পুনর্লিখন করা হয়নি।

## 4. বাধ্যতামূলক গেট — আগে এগুলো শেষ করতে হবে

বর্তমান `PHASE-2-VERIFICATION-STATUS.md` অনুযায়ী Phase 2 এখনও **IMPLEMENTED — UNVERIFIED**। Phase 3-এর feature development শুরু করার আগে:

1. GitHub-এ `main` branch থেকে `generate-lockfile` workflow চালান।
2. workflow যদি Better Auth version, dependency, typecheck বা lint error দেখায়, error summary/log সংগ্রহ করুন; failure bypass করবেন না।
3. generated lockfile এবং pin পরিবর্তন review করুন।
4. আলাদা PR/branch ব্যবহার করা হবে না; workflow সফল হলে main-এ normal push হবে।
5. `ci`, CodeQL এবং dependency-review green না হওয়া পর্যন্ত merge করবেন না।
6. CI-তে PostgreSQL integration/RLS tests সত্যিই green কি না নিশ্চিত করুন।
7. এরপরই Core Link Management-এর কাজ শুরু করা নিরাপদ।

## 6. Free hosting / Android constraint

- বর্তমান app static-only নয়; Node.js runtime এবং PostgreSQL দরকার।
- Cloudflare Pages একা PostgreSQL চালায় না। Cloudflare Workers-এ Next.js চালাতে adapter/runtime compatibility আলাদাভাবে যাচাই করতে হবে এবং PostgreSQL-এর জন্য আলাদা provider লাগবে।
- D1 হলো SQLite-ভিত্তিক Cloudflare database; এটি বর্তমান PostgreSQL schema-র drop-in replacement নয়। শুধু host বদলে D1-এ deploy করা নিরাপদ নয়।
- ফ্রি tier ও credit-card policy provider অনুযায়ী বদলায়। কোনো provider-এর বর্তমান free eligibility এই ZIP থেকে যাচাই করা হয়নি।
- GitHub Actions-এ dependency install/build/test চালানো যায়; Android ফোন থেকে GitHub web UI দিয়ে workflow চালানো সম্ভব। তবে GitHub-এ green CI হওয়া ছাড়া code verified বলে দাবি করা যাবে না।
